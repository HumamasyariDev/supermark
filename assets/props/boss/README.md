# Boss arena props (The Wolf's Own Tale)

Generated by the TOPUP_WORLDS track on night 01. Every folder has its own README with size, sockets and collision.

| Folder | Item | Replaces |
| --- | --- | --- |
| `boss_chimney/` | Intact brick chimney (BOSS-M01) | `BossChimney` box stack |
| `boss_chimney_broken/` | Broken stump and rubble (BOSS-M02) | box rubble pile in `BossChimney.smash()` |
| `tea_trolley/` | Wolf's tea trolley (BOSS-M03) with `teapot_socket` | `TeaTrolley` boxes in `wolf_rooftop.gd` |
| `teapot/` | Silver teapot (BOSS-M13): lob projectile and trolley pot | sphere + cone |
| `_preview/` | Look-dev scenes, not levels: `TopupBossPreview`, `TopupW1Preview`, `TopupW2Preview` and `TopupW3Preview` (each uses the world's real `env_*.tres` and sun), plus `TopupBossInArena.tscn` with `topup_arena_swap.gd`, which swaps the arena's chimneys and trolley for these meshes at runtime without editing the boss files | |

Integration belongs to the enemies/boss owner (`game/scripts/boss/`). `_preview/topup_arena_swap.gd` is the working recipe:
chimney scale 0.7 fits `BossChimney.size` (1.9 x 3.6 x 1.9), trolley scale 1.25, teapot 0.7 on the socket.
